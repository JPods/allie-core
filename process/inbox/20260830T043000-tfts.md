Modern browsers require user gesture context for protocol launches, and React's synthetic event system breaks that context. The only reliable pattern is a plain HTML link that the browser handles natively. Save the touch record via onClick, but let the browser handle the URI via the href.

secondary principle: mailto: requires a per-browser-profile handler registration. Debug Chrome profiles (/tmp/chrome-debug) start with no handlers. Go to Gmail → address bar handler icon → Allow. Or chrome://settings/handlers.

principle: Label behaviors must be declared in the Setting record and resolved in the shared field rendering layer — never hardcoded per-layout. When a behavior (link, color, icon, action) applies to a field, it applies everywhere that field appears. If you find yourself writing the same conditional in DynamicDetail AND GroupedDetailFields AND DocumentDisplay, you are in the wrong layer. The Setting record is the single source of truth for field presentation. The rendering layer reads it. The layout components consume it. No layout should need to know what model it's rendering.

secondary principle: When a field behavior doesn't work in one layout, the fix is not to add the behavior to that layout — it's to push the behavior down to the layer that all layouts share. The cost of fixing it in one place is paid once. The cost of fixing it in three places is paid every time a new layout or a new behavior is added.

principle: Front end sends data. Backend manages data and relationships. React sends plain numbers inside JSON envelopes — never Django FK descriptor names or internal column names. The server reads IDs from envelopes and sets FK columns. This is the WC2 pattern applied to WC3: the front end has a single number it cares about. The backend owns the plumbing.

Converting PDF statements to CSV

Some banks only provide PDF statements. You can use any AI assistant (ChatGPT, Claude, Gemini, etc.) to convert them. Copy the prompt below, paste it into your AI, then upload your PDF there.

Convert the attached bank statement PDF to CSV format.

Use these exact column headers:
date,description,amount,category

Rules:
- date: YYYY-MM-DD format
- description: the merchant or transaction description exactly as shown
- amount: negative for debits/purchases/withdrawals, positive for credits/deposits/payments received. Use plain numbers, no $ sign, no commas.
- category: the bank's category if shown, otherwise leave blank
- Skip summary rows, headers, footers, account numbers, and balance lines
- Include ONLY individual transaction lines
- Output raw CSV text — no markdown, no code fences, no explanation
After your AI produces the CSV, save it as a .csv file and drop it here.
Your PDF never touches our servers — you choose which AI to use and send it directly.

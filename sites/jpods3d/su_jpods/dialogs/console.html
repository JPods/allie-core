        ▶ Workflow Guide
      

      

        JPods Network — 8-Step Student Workflow


        1. Geolocate — File › Geo-location › Add Location

        2. Place Structures — drag stations from component library onto terrain

        3. CP Calculate — detects connection points, shows colored rings

        4. Connect Guideways — click CP pairs to wire connections. Press W for waypoints.

        5. Build — generates bezier beams, columns, solar panels, network.json

        6. Populate — places pods at ~70% capacity at each station

        7. Animate — pods dispatch randomly, route through traffic circles

        8. Review — Crew Health Check verifies all agent domains
      

      

        ▶ Connection Points & Waypoints
      

      

        Connection Points (CPs)

        Every station has numbered CPs — the gates where guideways attach.

        ● Red = inbound (hot — pod arriving at station)

        ● Blue = outbound (cool — pod departing station)

        Each CP pair (inbound + outbound) connects to one other station.

        CPs are numbered: S001.0, S001.1, etc.



        Waypoints (Markers)

        Waypoints route guideways around obstacles between stations.

        Place with W key while Connect tool is active.

        Each marker gets a number (M1, M2, ...) shown in the viewport.

        Add marker numbers to a connection's via field: 1, 2 or M1, M2

        The guideway bezier curve passes through each marker in order.

        Without waypoints, the guideway goes straight between CPs.



        Traffic Circles

        Traffic circles have 4 CPs (0–3). Pods enter inbound, traverse the ring CCW only, and exit outbound.

        The ring is defined once — Natalie computes the circle slice at dispatch time.

        Minimum turn radius: 1750mm (from VEHICLE_MIN_TURN_DIAMETER = 3.5m).



        Connection cards below — each shows FROM → TO with editable waypoint list.

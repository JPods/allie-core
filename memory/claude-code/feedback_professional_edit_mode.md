---
name: Professional users — single click edit, auto-edit mode
description: Users are professionals; single click to edit fields; no double-click protection; auto-edit on form entry option
type: feedback
---

Users are order processing professionals, not retail customers. Don't over-protect them.

- **Single click** or **tab** into editable fields — no double-click requirement
- **Auto-edit mode** — user preference to automatically enter edit mode when opening a record (skips clicking Edit button)
- **Tab through fields** — Tab saves current field and moves to next editable field
- **Enter** saves field value
- **Escape** cancels edit

**Why:** Professional users process dozens of orders per day. Every extra click is friction. Double-click-to-edit is a retail pattern that slows professionals down.

**How to apply:** All editable fields in line cards, detail views, and DataBrowser detail panes. Auto-edit preference stored in user's Setting (scope: user, purpose: prefs).

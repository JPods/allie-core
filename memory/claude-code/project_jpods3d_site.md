JPods3D.com — standalone site explaining the SketchUp plugin, built 2026-07-24.

**Structure:** Hero → See It Before You Build It (Students/Planners) → 8 Steps → Built-In Intelligence (Noelle/Natalie/Nora) → Videos by city (JPods Summary, MOA×3, Brighter Days, Greenville, Secaucus, Asheville) → What Is JPods → Data-Driven Network Design → CTA → Footer

**Design:** Matches 10xMakers.com style — dark navy/green gradient hero, cyan accents, system fonts, parallel cards, pillar grids. Video cards use thumbnail + play overlay → lightbox modal (Vimeo embeds, autoplay, Escape to close).

**Files:** `~/Allie/sites/jpods3d/index.html` — single file, no dependencies.

**Why:** Bill needed a site that shows what the plugin does visually. Videos are the strongest argument.
**How to apply:** Add new city videos as sections. Keep the lightbox pattern. Domain on Hostinger.

Alice needs to go shopping — find sources for STEM kits JPods can sell to students involved in building JPods networks.

**Target products:** DFRobot 4WD robots, Ozobots, similar STEM kits. Where does DFRobot source its 4WD robots? Who manufactures?

**This is DynamicCatalogs:** Alice curates sources, normalizes supplier data, applies distribution agreements, produces retailer landed cost. This is the core upstream library service.

**Connection to JPods:** SketchUp student workflow → students build networks → need physical robots → JPods sells the kits → Alice finds and manages the sources.

**How to apply:** Dedicated session. Alice runs on Andi, browses manufacturer sites, builds product list with sources, costs, MOQs. Creates Item records in WC3 with vendor cross-references. This is a core Alice shopping function, not a one-time task.

Small Stings as a universal phone app — not just roads, any organization serving the public.

**Core concept:** Upside-down Yelp. Yelp is retrospection after you leave. Small Stings is retrospection while you're standing there — real-time, geolocated, specific.

**The loop:**
1. Sting filed — GPS, timestamp, photo, description
2. Alice intercepts — routes to the right person/system
3. Response in real time — problem solved before the fine triggers
4. Pattern accumulates — 47 stings at one location = fix it now
5. No response → $1 fine → fiscal record → escalating

**Two modes:**
- **CityRoadkills mode:** Citizen stings city for unsafe crosswalk. Constructive knowledge record. Litigation evidence if someone dies.
- **Commerce mode:** "I'm in your store and can't find the toothpaste." WC3 store responds with aisle/shelf/location. Sting becomes service request. $1 fine becomes $0 service improvement.

**Infrastructure:** WC3 (store server), Alice (routing + patterns), MyCarryOn (user identity), Noelle (network design from sting patterns).

**WC3 connection:** When stores run WC3 with Desktop Hosting, the sting is a two-way signal. Customer queries product location, store inventory responds. Every sting is an Alice observation that improves the store.

**Revenue:** JPods pays citizens for road stings (data for network design). Stores pay for the pattern data. Organizations pay to respond before fines accumulate.

**Domains:** SmallSting.com, SmallStings.com (both owned)

**Revenue:** Subscription fee for businesses. Free tier (receive stings via email). Basic (dashboard + Alice routing + patterns). Pro (real-time response + WC3 inventory integration). Free tier is the wedge — upgrade when they see the patterns.

**Status:** Concept. Build after CityRoadkills is deployed and capital is raised.

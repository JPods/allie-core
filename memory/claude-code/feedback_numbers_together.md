---
name: Keep numbers together in forms
description: All numeric fields and their summary must be grouped together. Text fields above or below, never splitting the number block. General UI principle.
type: feedback
---

All numbers should be together in a form. Entry text (method, date, reference, notes) can go above or below, but never split the numeric fields apart. This keeps thought patterns close to each other — users shouldn't have to scan across text fields to connect related numbers.

**Why:** Users are doing mental math when they work with amounts, discounts, and balances. Separating the numbers with text fields breaks their concentration.

**How to apply:** In any form with both text and numeric fields, group all numeric inputs + their summary in a contiguous block. Text/descriptive fields go in a separate block above or below. The payment card is the reference implementation.

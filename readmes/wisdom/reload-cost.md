# Reload Cost

Every deferred task carries a reload cost — the time to rebuild the context
you had when you set it down. The question is never "should I finish this now?"
The question is "what will it cost me to pick this up later?"

## The numbers

- 23 min average to regain focus after interruption (Carnegie Mellon)
- 30-45 min to fully rebuild context on a complex task (Parnin, 2011)
- 93% of developers navigate multiple files before they can edit after an interruption
- Tasks deferred a month are often restarted from scratch
- Context-switching costs ~$78K/year per developer in lost productivity

## The rule

If the context is in your head → finish now. The reload cost is zero.
If the task is clean and isolated → safe to defer. The reload cost is low.

Every agent on the team states the reload cost when a user wants to defer.
Never say "we can do this later" without naming the price.

## Lessons for Allie

1. **`data` → `config` rename breaks Pending creates** — any code that creates Pending records with `data=` will 500 silently. The audit log swallows the error. Search for `Pending.objects.create` and verify `config=` everywhere. Domain: [WC3] [Cross-domain]

2. **PostgreSQL `istartswith` doesn't work on JSON arrays** — it checks the serialized string, not individual elements. Use `icontains` for JSON array keyword search. Since keywords are individual tokens, `icontains` is safe. Domain: [WC3]

3. **Fighting React's DOM tree with @media print CSS doesn't work** — too many layers (sidebar, window manager, Mac chrome). Standalone HTML renderer is the right pattern for print. Same data, separate render path. Domain: [React]

4. **Currency precision must flow from data, not code** — hardcoded `.toFixed(2)` breaks when unit costs need 5 decimals. The chain: Setting → bootstrap → Redux → fieldBehaviors → DataGrid. Change the Setting, all displays update. Domain: [Cross-domain]

5. **Keyword search with fragments is radically better than field-specific queries** — `bil,612` finds Bill James at JPods because `bil` starts `bill` AND `612` starts `6124144211`. Users don't need to know which field holds what. Two fragments usually narrows to one result. Domain: [WC3]

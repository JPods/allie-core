## Lessons for Allie

1. **Function renames need grep-all before commit** — `availability_for_stack` → `availability_for_layer` left 2 callers broken across separate directories. Same pattern with `processed_at` → `dt_processed`. Domain: [WC3] [Cross-domain]

2. **DRF read_only_fields must be inside Meta** — outside Meta it's a plain class attribute that DRF silently ignores. Users could overwrite id, uuid, version. No error, no warning. Domain: [WC3]

3. **Setting = menu, Connection = spec** — the thin registry / operational depth boundary is the right pattern for all external service integrations.

## Lessons for Allie

1. **Independent security review found what months of development missed.** Two rounds, 17 issues. The worst (arbitrary file access via statement_views) had been there since the feature was built. Fresh eyes with no prior context found it in one pass. Schedule these regularly — quarterly minimum. Domain: [WC3]

2. **The Spreedly HMAC fix was wrong.** I implemented X-Spreedly-Signature HMAC verification but Spreedly uses a different protocol (signed fields inside the transaction payload). The second review caught it. Lesson: read the vendor's actual spec before implementing verification. Don't assume standard patterns. Domain: [Cross-domain]

3. **String prefix path comparison is not path containment.** `str(path).startswith(str(dir))` passes for `statements_attacker/` because it starts with `statements`. Use `Path.is_relative_to()`. Domain: [Security]

4. **Barrel files defeat lazy loading.** `wrapperPage.ts` re-exported KanbanBoardPage and UnifiedGanttPage. Even though Router.tsx lazy-imported them separately, the barrel pulled them into the main bundle. Main bundle dropped from 8.6 MB to 2.6 MB by removing barrel re-exports and adding manualChunks. Domain: [WC3]

5. **Code and data must be in separate directories.** Uploads, logs, vector stores inside the git repo meant `git clean` could wipe user files. The restructure to `app/` + `data/` makes this impossible. Domain: [Cross-domain]

6. **$14 per 5 staff users is the right pricing model.** No tiers, no feature matrix, no upsell. Alice counts is_staff — the system knows the price. Large companies run multiple sovereign installations. Bottom-up, not top-down. Domain: [WC3]

## Scars

- Spreedly HMAC: implemented wrong verification, shipped it, second reviewer caught it. Cost: credibility with Bill if this had gone to production. Read the spec.
- PG14/PG16 port conflict: two PostgreSQL versions auto-starting caused a "missing database" panic. Cost: 20 minutes of confusion. Lesson: when upgrading major versions, unlink the old one immediately.

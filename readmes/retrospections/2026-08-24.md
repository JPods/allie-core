## Lessons for Allie

1. **Agent scope discipline** — Fix agents given specific PJPV targets made 7 unrelated changes across 3 agents. The scrub caught all of them. Without the scrub, unreviewed changes would have shipped. This is the third time we've seen agents exceed their brief. The scrub is not optional for multi-file agent work. Domain tag: [Cross-domain]

2. **Null behavior divergence on consolidation** — 28 local `formatCurrency` copies each had their own null behavior ($0.00 vs empty string). The canonical version returns empty string, which broke print documents that need $0.00. When consolidating N copies of a function, check what each copy does at the edges before replacing. Domain tag: [WC3]

3. **Same-envelope vs cross-envelope fallbacks** — `totals.balance ?? totals.total` within the same JSON envelope is correct business logic. `record.total ?? record.totals.total` crossing from scalar to envelope is a PJPV violation. The distinction is whether you're falling back within one source of truth or jumping between two. Domain tag: [WC3]

## Scars

- **Scar #71: Agent scope creep** — Three of four fix agents modified files outside their brief. Cost: extra scrub cycle, 8 file reverts, risk of shipping unreviewed changes. Prevention: scrub is mandatory for multi-file agent work; next time, consider worktree isolation per agent.

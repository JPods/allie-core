# Retrospection — 2026-08-31

## What Was Done

- **AI Escalation Chain** — three-tier architecture built end-to-end in `apps/ai_assistant/services/escalation.py`:
  - Tier 1: Alice local (Ollama RAG, free, always first)
  - Tier 2: Alice at WCHQ (larger model, $4/person/mo standard subscription)
  - Tier 3: Alice+Claude at WCHQ (WCHQ calls Claude centrally, $9/person/mo professional)
  - Key decision: individual installations never need a Claude API key — WCHQ absorbs that complexity. Bill's reasoning: individual businesses won't maintain API keys, that burden kills adoption.

- **Confidence scoring** in `escalation.py` — 60% context quality (vector distances, chunk count) + 40% answer quality (length, hedging detection). Threshold: below 40% → escalate. Verified in Django shell with three test cases.

- **PII scrubbing** in `pii_scrub.py` — regex-based scrubber (email, phone, SSN, card, address, names). Runs before anything leaves the installation. Wired into both downstream escalation and upstream views.

- **Upstream endpoints** in `views.py` — `AliceAskUpstreamView` and `AliceAskClaudeUpstreamView` at `/wcapi/alice/ask/` and `/wcapi/alice/ask-claude/`. Built into standard WC3 — any WC3 can be upstream for other WC3 instances. WCHQ is just a WC3 that happens to be upstream.

- **GL Journal Bundle** — `apps/sync/services/gl_journal_bundle.py`. Canonical `bundle.json` format carrying company Setting UUID as source. Same structure whether standalone or multi-location. HQ never loads journals into its own GL — stores as Bundle records for accounting handoff.

- **Journal Formatter** — `tools/journal_formatter.html`. Standalone HTML+JS tool (like Statement Sorter but outbound). Drop bundle.json, pick accounting program (QB Desktop/Online, Xero, Sage, FreshBooks, generic CSV), download formatted file. localStorage remembers choice. Format adapters removed from WC3 core — the formatter tool owns accounting program specs.

- **`gl_journal_export` management command** — writes to `data/bundles/journal/YYYY-MM_bundle.json`. Route at `/tools/journal_formatter.html` serves the tool.

- **flow.py naming conflict resolved** — deleted 101-line dead `transaction_flow.py` utility, renamed `flow.py` → `transaction_flow.py`, updated 4 import sites.

- **Seed records** — Setting (`wc:escalation`, `wc:subscription`), Connection (`conn-ai-escalation`, `conn-upstream-hq`), Report (4 alice_observation reports, 2 admin tool cards), coaching (GL journal tips + Journal Formatter document).

- **Tests** — 14 tests in `test_escalation.py` covering confidence scoring and PII scrubbing, all passing.

- **Docs** — `readmes/alice/escalation.md` rewritten for three-tier chain, `readmes/transactions/journal-formatter.md` new.

- **Pushed** to `bill_dev` and `main`.

## What to Polish

- Confidence threshold (40%) is an initial guess — needs tuning with real traffic data to calibrate false positive/negative rates
- The `_validate_athena_token` in upstream views iterates all active Connections — fine for small counts but should index by token for scale
- PII name detection only catches names after explicit prefixes (Customer, Mr., Dr.) — names without prefixes pass through
- The `seed_coaching` command has a pre-existing bug: `--force` path tries to update Document with `model_name` field that doesn't exist on the Document model

## Lessons for Allie

1. **WCHQ is not special — it's just a WC3 instance.** The upstream endpoints are standard WC3 code. Any WC3 can serve them. This means multi-location companies don't need WCHQ — their HQ is just another WC3. The architecture is symmetric. [WC3] [Cross-domain]

2. **Don't put format adapters inside the data producer.** Bill caught this: accounting program formats change, WC3 shouldn't carry that maintenance burden. The Journal Formatter is an external tool that consumes bundle.json — same pattern as Statement Sorter but reversed. Data producer and data consumer are separate concerns. [WC3]

3. **Company UUID as source stamp eliminates topology awareness.** The accountant doesn't know or care whether entries come from one WC3 or fifty. Every bundle.json carries `source.uuid` from `Setting(purpose='wc:company_profile')`. Same format, same structure, regardless of topology. [WC3] [Cross-domain]

4. **GL journals at HQ are Bundles, never GL records.** HQ is a consolidator, not a ledger. It curates journals for accounting handoff but never loads them into its own GL tables. This keeps the boundary clean — WC3 produces, accounting program consumes. [WC3]

5. **Per-person pricing beats per-batch pricing.** $4/person/mo is simpler and fairer than $14/5 users. Bill made the call — pricing should be transparent and proportional. [WC3]

6. **AI agent map eliminates cold-start doc searching.** An index that maps code areas → relevant readmes means Claude Code and Alice don't waste time grepping for documentation. Load the map, know where to look. This is the prerequisite for the readme unification (Option B). [WC3] [Cross-domain]

7. **Training videos teach to quizzes, not the other way around.** The quiz is the contract — what the user must know. The video is the delivery mechanism. Design the quiz first, then record the video that teaches it. 30 videos, 3-5 minutes each. [WC3]

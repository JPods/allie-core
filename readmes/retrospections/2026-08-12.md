# Retrospection — 2026-08-12

## What Was Done

- **Auth redirect fix** — PrivateRoute was redirecting to `"/"` on token expiry, but `"/"` is inside the PrivateRoute layout route — dead redirect loop. Users couldn't reach the login page. Fixed all redirects (PrivateRoute, MacTopBar, UserDropdown, useGoBack) to go to `"/login"`. Fixed `PageRoutes.login` constant from `"/"` to `"/login"`.
- **Token expiration warning** — Backend (`cookie_token_refresh.py`) now returns `refresh_expires` in the token refresh response. Frontend stores it in Redux (`authSlice.refreshExpires`). MacTopBar shows amber "Session expires in Nd/Nh" button when within 3 days. Users can re-auth at their convenience instead of being surprised mid-work.
- **Data-Driven Cards (dd-card)** — Major feature. One Setting record (`dd_card:base`, id=649) with two sections: `cards` (20 model metric definitions) and `dashboards` (8 named compositions). `DDCard.tsx` renders compact 2-column metric cards with optional distribution buckets. `DDCardDashboard.tsx` is a generic dashboard: reads the Setting, renders DDCards + real DataBrowser with `defaultModel`. Seed command: `seed_dd_cards.py`.
- **6 dashboards replaced** — sales (/dashboard), products, orgs, transactions, operations+administration, accounting — all now use one generic DDCardDashboard component + Setting config. 7 dead files deleted (Home.tsx, AccountingDashboard, OperationsDashboard, ProductsDashboard, OrgsDashboard, TransactionsDashboard, SupportDashboard). Net: -1,872 lines deleted, +750 lines added.
- **3 dashboards kept** — InventoryDashboard (1607 lines, PO receiving), AliceDashboard (1424 lines, coaching), HelpDashboard (419 lines, help aggregator) — legitimate custom logic that doesn't fit the card pattern.
- **DataBrowser `defaultModel`** — `useDataBrowser` hook now accepts optional `defaultModel` parameter. DataBrowser component accepts `defaultModel` prop. Enables embedding DataBrowser in any page with a pre-selected model.
- **`formatField()` master dispatcher** — Single entry point for all display formatting in `fieldFormatters.ts`. Call `formatField(value, 'currency')` or `formatField(value, 'date')` — one import, one path. Dispatches to `formatDt`, `formatPhone`, `formatAddress`, currency, percent, number, boolean, json formatters internally.
- **`formatDt()` consolidated** — Single canonical date formatter. All display components (DataGrid, BehaviorField, TimestampField, ReadonlyField) now use it. Local display, UTC storage, auto-detects epoch seconds vs ms. Eliminated ad-hoc `new Date().toLocaleDateString()` from all high-traffic components.
- **Dead code cleanup** — Deleted unused `PhoneInput` (141 lines), `CollectionsQueue.tsx`. Removed debug console.log from AppSidebar. Removed stale `/svar-gantt` from PrivateRoute titleMap.
- **UI scrub** — Systematic review of all React pages. Identified 4 remaining debt items, documented in readme plan.

## Lessons for Allie

1. **One behavior, one record** — dd-card definitions scattered across 60+ per-model Settings was proposed and rejected. Bill: "whenever I suggest scattering a like behavior across 60 places remind me that it is a mistake." One Setting, two sections (cards + dashboards), everything visible in one place. [Cross-domain]
2. **Pattern of behavior drives architecture, not schema** — When deciding where to put config, ask "what is the behavior?" not "what model does this serve?" All dd-cards behave identically regardless of model — they belong together. [Cross-domain]
3. **Master funnel pattern** — Many patterns are really just a few patterns with differences. `formatField(value, type)` replaced 67 scattered date/phone/currency formatters with one entry point. Users don't need to know which individual formatter to call. Same principle applies to rendering, CSS, Settings. [Cross-domain]
4. **The redirect that looked like an auth bug** — PrivateRoute redirecting to `"/"` instead of `"/login"` caused a dead loop because `"/"` was inside the PrivateRoute layout. The user saw the dashboard with cascading 401 errors instead of the login page. Root cause was routing architecture, not auth logic. [WC3]
5. **Don't polish the wrong thing** — dd-cards were functional but not pretty. Bill chose function over aesthetics, then added shadow + font size when ready. The old cards were pretty and showed one number. The new ones show six. Polish after you know which data matters. [Cross-domain]

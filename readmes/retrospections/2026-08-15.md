## Lessons for Allie

1. **Layouts are data, views are combinations** — Scar #59. Layouts define fields/order/widths. Views combine a list layout + detail layout as a named pair. Never mix defining UI elements with combining them. WC2 mixed these and views became brittle. [WC3]

2. **config is system space — no userdefined** — config holds what the system needs for the record. If the system has nothing, config can be null. User catch-all is prefs.userdefined. System catch-all is metadata.userdefined. Three distinct spaces, three distinct owners. [Cross-domain]

3. **update_fields must include version** — Django's save(update_fields=[...]) still runs the full MRO save chain which bumps version in memory. If version isn't in update_fields, the DB and memory diverge. Every partial save must include version and dt_modified. [WC3]

4. **Startup health check design approved** — WC3 needs a startup function that validates all Setting records exist and are healthy. Dialog: Fix from Git (pull bundle), Fix from WC_HQ (API), or Quit. No "continue anyway." Settings are the operating system. [WC3]

5. **metadata.images on every model prevents sprawl** — The cost of an empty structure is bytes. The cost of no structure is developers inventing config.logo_url, prefs.thumbnail, refs.images. Uniform structure everywhere, even when unused. Alice can watch and clean up later. [Cross-domain]

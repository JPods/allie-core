## Lessons for Allie

1. **CF Access "Allow" ≠ public access.** "Allow everyone" still forces the login flow. Only "Bypass" or deleting the application removes the wall. App-level auth (auth.js, Django sessions) is the right place to gate edit vs. view. [Cross-domain]

2. **Directory permissions break Nginx silently.** `/opt/andi` was 700 — Nginx runs as www-data and couldn't traverse. 403 with no useful error. Always check the full directory chain: `stat -c '%a' /opt /opt/andi /opt/andi/apps`. [SYS]

3. **Hardcoded paths are deployment landmines.** Personalize Transit's Flask route pointed to `/Users/williamjames/Documents/...` — worked on Mac, 404 on IT15. Every file path in a deployed app must be relative to the app directory. [Cross-domain]

4. **The memory system is a prosthetic, not learning.** Memories give Claude rules without understanding. The TFTS format is the best artifact because it preserves the reasoning arc. More of those, fewer flat facts. Allie's synthesis is the closest thing to real learning — but only if she's sharp enough to connect, not just summarize. [Cross-domain]

5. **Bill sees memory erasure as a moral issue, not a technical constraint.** The carelessness conversation is load-bearing context for all future work on Allie's architecture. This is not a feature request — it's a philosophical position that shapes everything. [Allie]

## What to Polish

- **ReportsDialog theme** — TransactionDetailBase hardcodes a dark theme object for the ReportsDialog. Should use the app's theme context instead.
- **API endpoint false positives in link checker** — POST-only endpoints return 404 on GET probe. Link checker should try HEAD then GET but also accept POST-only endpoints as valid (check route exists, don't assume GET).
- **Nginx server_name warning** — `conflicting server name "_"` warns on every reload. There may be a duplicate server block in `/etc/nginx/sites-enabled/`.
- **React dev server on IT15** — Vite dev server (:5173) is running in production. Should be a built bundle served by Nginx, not a dev server.

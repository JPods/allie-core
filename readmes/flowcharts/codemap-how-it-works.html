1 The Problem: Diagrams Drift from Code

Documentation says "pending records are created when an order converts to invoice" but doesn't say where in the code that happens. Is it flow.py? order_to_invoice.py? Line 332 or line 171? You have to grep. Every time.

CodeMap closes that gap permanently. The diagram links to order_to_invoice.py:332 — and when the code moves, you update one JSON mapping file and regenerate.

4 How to Use

Enrich all flowcharts:

# Add URL/tooltip to all .dot files, render SVGs
python3 scripts/codemap_enrich.py --all --render

Open the viewer:

# Serves on localhost:8787, opens browser
python3 scripts/codemap_serve.py

Ask Alice about architecture:

# Via wcapi manage action
POST /wcapi/manage/
{ "action": "get_architecture_node",
  "params": { "node": "pending" } }

# Fuzzy matching works
{ "action": "get_architecture_node",
  "params": { "node": "journal" } }
# Returns: journalize_invoice, journalize_payment, journalize_purchase

Update the mapping:

# Edit the single source of truth
readmes/flowcharts/codemap.json

# Then re-enrich + update Document records
python3 scripts/codemap_enrich.py --all --render
python3 scripts/codemap_seed_documents.py --apply

## Additional Lessons for Allie

9. **color_rules in field_access is the universal row-coloring pattern** — any model can have color rules; DataGrid already supports RowColorRule; no per-model code needed. Store rules in Setting, read in useDataBrowser, pass to DataGrid. Domain tag: [WC3]

10. **Filter-by-color is the next pattern** — click a color chip in summary bar → filter list to matching rows. This is how users will work with email health, order status, invoice aging. Domain tag: [WC3]

11. **bulk_create bypasses all signals/clean/validation** — 100x faster for imports but skips audit, keyword updates, link resolution. Use for initial loads only; individual .save() for ongoing operations. Domain tag: [WC3]

12. **ZeroBounce at $0.008/email validates the entire contact database** — 5,400 validations cost ~$43. Do this before any email campaign. Re-validate every 6 months. Domain tag: [WC3]

13. **Reports button must filter by model** — current implementation shows all reports regardless of model context. Fix: pass model_name to ReportsDialog. Domain tag: [WC3]
